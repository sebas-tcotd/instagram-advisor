<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → src/cli/*.ts | User-supplied command-line arguments (photo path, format, tone) are untrusted strings |
| CLI → process.env | API keys read at runtime from environment variables |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | CLI photo path argument traversal | accept | CLI is a personal local tool; the user supplies the path; no server-side path sanitization needed |
| T-05-02 | Information Disclosure | ANTHROPIC_API_KEY printed in error output | mitigate | CLI error messages never print the apiKey value; only the presence/absence is logged in doctor.ts |
| T-05-03 | Denial of Service | CLI hanging on missing API key (no timeout) | accept | Personal tool; user controls environment; a missing key produces an API error within seconds from the provider |
| T-05-SC | Tampering | npm/pnpm installs | mitigate | No new packages; tsx already installed in Plan 01-01 |
</threat_model>

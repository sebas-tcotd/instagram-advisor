<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI process.env → loadConfig | API keys read from environment at runtime; never written to files |
| AI API response → provider parse | Raw string from external API is untrusted; must be validated before returning typed domain object |
| config.yaml prompts_dir → readFileSync | prompts_dir value controls which files are read; this is developer-controlled in v1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | API keys in loadConfig() process.env | mitigate | Keys read from env vars at runtime only; never written to config.yaml or any tracked file; apiKey field is not logged or exposed in errors |
| T-03-02 | Tampering | Malformed AI JSON response injected into domain layer | mitigate | Both providers validate response shape before returning typed object (D-06); throws Error on invalid shape instead of returning malformed data; React JSX escapes rendered strings |
| T-03-03 | Tampering | config.yaml prompts_dir path traversal | accept | In v1, only the repo owner runs this tool locally; prompts_dir is not user-supplied input; no path sanitization needed for a personal tool |
| T-03-04 | Elevation of Privilege | Infrastructure layer importing from application or ui | mitigate | eslint-plugin-boundaries allows infrastructure to import domain, application, infrastructure only; lint runs in verification |
| T-03-SC | Tampering | npm/pnpm installs | mitigate | No new packages in this plan; all providers use already-installed @anthropic-ai/sdk and @google/genai; js-yaml already installed |
</threat_model>

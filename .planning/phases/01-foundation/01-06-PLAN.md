## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Gemini REST API | API key embedded in Vite bundle at build time (VITE_GEMINI_API_KEY) |
| prompts/?raw → Vite bundle | Prompt files inlined at build time; no runtime filesystem access |
| AI JSON response → React state → DOM | Untrusted string from AI API rendered via React JSX (auto-escaped) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | VITE_GEMINI_API_KEY inlined in browser bundle | accept | Accepted per CONTEXT.md and ARCHITECTURE.md; personal local tool only; dist/ is gitignored (fixed in Plan 01-01); key visible in DevTools but tool is for personal use only |
| T-06-02 | Tampering | AI JSON response rendered in DOM | mitigate | React JSX auto-escapes all string interpolations; verdict/scores are TypeScript union types preventing unexpected values; useAIProvider hook validates shape before setting result state |
| T-06-03 | Tampering | config.yaml?raw provider value controlling UI provider | accept | Build-time config; developer-controlled; no user input involved in provider selection |
| T-06-04 | Information Disclosure | prompts/*.md inlined in production Vite bundle | accept | Prompts contain the personal strategy document; acceptable for a personal tool; dist/ is gitignored |
| T-06-SC | Tampering | npm/pnpm installs | mitigate | No new packages in this plan |
</threat_model>
